# Calculator

A simple calculator built with HTML, CSS, and JavaScript as part of
[The Odin Project](https://www.theodinproject.com/lessons/foundations-calculator) Foundations course.

The goal of this project was to practice JavaScript fundamentals, DOM manipulation,
event handling, and implementing calculator logic without relying on external libraries.

## Live Demo

Try the calculator here:

**[Live Calculator](https://bobvanveendev.github.io/calculator/)**

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Support for consecutive calculations.
- Decimal number input with validation.
- Automatic leading zero for decimal inputs (e.g., `.5` becomes `0.5`).
- Results rounded to a maximum of six decimal places.
- Clear button to reset the calculator.
- Backspace button to remove the last entered character.
- Keyboard support for numbers, operators, and calculator controls.
- Error handling for division by zero.
- Prevention of invalid calculations and multiple decimal points.

## Technologies Used

- **HTML5** – Calculator structure.
- **CSS3** – Styling and layout using Flexbox.
- **JavaScript** – Calculator logic, DOM manipulation, and event handling.

## How to Use

You can use the calculator by clicking the buttons or using your keyboard.

### Keyboard Controls

| Key            | Action                |
| -------------- | --------------------- |
| `0–9`          | Enter numbers         |
| `+`            | Addition              |
| `-`            | Subtraction           |
| `*`            | Multiplication        |
| `/`            | Division              |
| `.`            | Decimal point         |
| `Enter` or `=` | Calculate result      |
| `Backspace`    | Delete last character |
| `Escape`       | Clear calculator      |

### Example

Enter the following calculation:

`12 + 7 - 1 =`

The calculator evaluates each operation in sequence and displays:

`18`
